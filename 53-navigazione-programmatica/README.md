# Lezione 53: navigazione programmatica con NavigationPath

Il progetto com'è alla fine della lezione.

L'elenco delle pizze con una navigazione controllata dal codice.

## Che cosa c'è dentro

- NavigationPath in una variabile di stato
- append per aprire una schermata dal codice
- Due tipi di valore con due navigationDestination
- Tornare alla schermata iniziale svuotando la pila

## Come aprirlo

Fate doppio clic su `Fondamenti.xcodeproj`. Il codice della lezione è in `Fondamenti/ContentView.swift`: l'anteprima compare accanto al codice, e con Command R l'app parte nel simulatore.

Il progetto è creato con Xcode 27.2, la versione usata nel corso.
