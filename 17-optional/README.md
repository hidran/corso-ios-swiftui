# Lezione 17: optional, il valore che può mancare

Il progetto com'è alla fine della lezione.

Gli optional nel blocco #Playground: un numero letto da un testo, if let ed else, il valore di riserva con ?? e l'optional chaining.

## Che cosa c'è dentro

- Int(_:) da un testo restituisce un optional
- if let, anche nella forma corta, con else
- ?? per un valore di riserva, anche con i dizionari
- Optional chaining: note?.count

## Come aprirlo

Fate doppio clic su `Fondamenti.xcodeproj` e aprite `Fondamenti/ContentView.swift`. Il codice della lezione è nel blocco `#Playground`, in fondo al file: se il canvas non è aperto, sceglietelo dal menu Editor > Canvas, e i risultati di ogni riga compaiono lì.

Il progetto è creato con Xcode 27.2, la versione usata nel corso.
