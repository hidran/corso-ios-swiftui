# Lezione 29: valore o riferimento: struct contro class

Il progetto com'è alla fine della lezione.

Una struct Order, le classi Table e Oven, e nel blocco #Playground la differenza tra copiare un valore e condividere un oggetto.

## Che cosa c'è dentro

- Una struct assegnata è una copia
- Una classe assegnata è lo stesso oggetto, anche con let
- === per lo stesso oggetto, == per lo stesso valore
- Una closure in una proprietà con [weak self] e guard let self

## Come aprirlo

Fate doppio clic su `Fondamenti.xcodeproj` e aprite `Fondamenti/ContentView.swift`. Il codice della lezione è nel blocco `#Playground`, in fondo al file: se il canvas non è aperto, sceglietelo dal menu Editor > Canvas, e i risultati di ogni riga compaiono lì.

Il progetto è creato con Xcode 27.2, la versione usata nel corso.
