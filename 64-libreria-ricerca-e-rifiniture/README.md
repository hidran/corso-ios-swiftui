# Lezione 64: Libreria: ricerca e rifiniture

Il progetto com'è alla fine della lezione.

Il progetto Libreria completo: ricerca, messaggio quando non c'è niente, scorrimento per eliminare e il conto dei libri letti.

## Che cosa c'è dentro

- searchable con una proprietà calcolata dei risultati
- ContentUnavailableView in un overlay
- swipeActions per eliminare un libro per id
- navigationSubtitle con il conto dei libri letti

## Come aprirlo

Fate doppio clic su `Fondamenti.xcodeproj`. Il codice della lezione è in `Fondamenti/ContentView.swift`: l'anteprima compare accanto al codice, e con Command R l'app parte nel simulatore.

Il progetto è creato con Xcode 27.2, la versione usata nel corso.
