# Lezione 60: anteprime efficaci

Il progetto com'è alla fine della lezione.

Le righe delle quantità con tre anteprime: la schermata intera, la riga da sola con uno stato di prova, e il tema scuro.

## Che cosa c'è dentro

- Più blocchi #Preview con un nome
- @Previewable @State per provare una view con un binding
- preferredColorScheme(.dark) in un'anteprima

## Come aprirlo

Fate doppio clic su `Fondamenti.xcodeproj`. Il codice della lezione è in `Fondamenti/ContentView.swift`: l'anteprima compare accanto al codice, e con Command R l'app parte nel simulatore.

Il progetto è creato con Xcode 27.2, la versione usata nel corso.
