# Lezione 13: set e dizionari

Il progetto com'è alla fine della lezione.

Set e dizionari nel blocco #Playground: gli ingredienti di una pizza in un set, il listino in un dizionario, e un dizionario che conta gli ordini.

## Che cosa c'è dentro

- Un set con insert, contains e intersection
- Un dizionario: aggiungere, cambiare e togliere con la chiave
- Leggere una chiave con default
- Il dizionario vuoto [:] e il conteggio con +=

## Come aprirlo

Fate doppio clic su `Fondamenti.xcodeproj` e aprite `Fondamenti/ContentView.swift`. Il codice della lezione è nel blocco `#Playground`, in fondo al file: se il canvas non è aperto, sceglietelo dal menu Editor > Canvas, e i risultati di ogni riga compaiono lì.

Il progetto è creato con Xcode 27.2, la versione usata nel corso.
