# Lezione 58: Layout adattivi: iPhone ridimensionabile e iPhone Duo

Il progetto com'è alla fine della lezione.

Una pizza e i suoi ingredienti disposti da ArrangementView (iOS 27.1): affiancati in orizzontale, uno sopra l'altro in verticale, con un VStack per iOS 26.

## Che cosa c'è dentro

- ArrangementView con lo stile split
- splitArrangementLayoutRatio
- if #available con un'alternativa per iOS 26
- Un'anteprima in orizzontale con traits

## Come aprirlo

Fate doppio clic su `Fondamenti.xcodeproj`. Il codice della lezione è in `Fondamenti/ContentView.swift`: l'anteprima compare accanto al codice, e con Command R l'app parte nel simulatore.

Il progetto è creato con Xcode 27.2, la versione usata nel corso.
