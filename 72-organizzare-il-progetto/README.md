# Lezione 72: Organizzare il progetto

Il progetto com'è alla fine della lezione.

La lista di cose da fare divisa in cartelle e file: il modello in Model, la riga in Views, la schermata principale in ContentView.

## Che cosa c'è dentro

- Model/Todo.swift: la struct Todo e i dati di esempio, con import Foundation
- Views/TodoRow.swift: la riga, con import SwiftUI
- ContentView.swift: solo la schermata principale

## Come aprirlo

Fate doppio clic su `Fondamenti.xcodeproj`. Nel navigatore a sinistra trovate le cartelle Model e Views dentro la cartella Fondamenti; l'anteprima di ContentView mostra la lista, e con Command B si compila tutto il progetto.

Il progetto è creato con Xcode 27.2, la versione usata nel corso.
