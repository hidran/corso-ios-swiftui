# Lezione 68: valori d'ambiente personalizzati

Il progetto com'è alla fine della lezione.

Le spese di un viaggio, con la valuta in un valore d'ambiente creato con @Entry: euro a Roma, sterline a Londra.

## Che cosa c'è dentro

- extension EnvironmentValues con @Entry
- @Environment(\.currencyCode) nella riga
- Un modificatore currencyCode(_:) in un'estensione di View

## Come aprirlo

Fate doppio clic su `Fondamenti.xcodeproj`. Il codice della lezione è in `Fondamenti/ContentView.swift`: l'anteprima compare accanto al codice, e con Command R l'app parte nel simulatore.

Il progetto è creato con Xcode 27.2, la versione usata nel corso.
