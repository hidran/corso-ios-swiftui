# Lezione 65: una sola fonte di verità

Il progetto com'è alla fine della lezione.

Un conto da dividere tra amici, con il numero di persone in un solo posto e la quota a testa calcolata.

## Che cosa c'è dentro

- Uno State con un solo proprietario, ContentView
- Un Binding per la view che cambia il dato
- Una proprietà calcolata invece di un secondo stato

## Come aprirlo

Fate doppio clic su `Fondamenti.xcodeproj`. Il codice della lezione è in `Fondamenti/ContentView.swift`: l'anteprima compare accanto al codice, e con Command R l'app parte nel simulatore.

Il progetto è creato con Xcode 27.2, la versione usata nel corso.
